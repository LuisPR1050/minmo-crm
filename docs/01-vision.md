# Visión del proyecto

Construir el sistema operativo digital de Felipe Parodi Asesor
Inmobiliario: un CRM que acompaña cada inmueble desde su captación
hasta la firma del acta de entrega, eliminando el trabajo manual en
la generación de documentos legales, dando trazabilidad completa a
cada negociación, y preparado para escalar a múltiples asesores,
integraciones con canales digitales y asistencia por IA.

Construido como monolito modular en Java 21 + Spring Boot,
mantenible por un solo desarrollador.
